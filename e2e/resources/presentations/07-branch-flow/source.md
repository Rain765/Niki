# 报销审批流程

> 合成评测材料。机构、人物和数字均为虚构，仅用于测试文档转 PPT。

## 角色

员工负责提交与补件；主管和总监负责业务审批；财务负责凭证复核与付款。拒绝结束后不再自动流向付款。

## 有向流程

员工提交 → 完整性校验：提交。

完整性校验 → 员工补件：资料不全。

员工补件 → 完整性校验：补件后重新校验。

完整性校验 → 主管审批：资料齐全。

主管审批 → 拒绝结束：不批准。

主管审批 → 金额判断：批准。

金额判断 → 财务复核：金额小于等于 5000 元。

金额判断 → 总监审批：金额大于 5000 元。

总监审批 → 拒绝结束：不批准。

总监审批 → 财务复核：批准。

财务复核 → 员工补件：凭证有误。

财务复核 → 付款归档：凭证正确。

## 例外和时限

5000 元整走普通财务复核路径，不能走“大于 5000 元”分支。补件后回到完整性校验，不直接跳过主管审批。主管须在 2 个工作日内处理；超时通知申请人和代理主管，不自动批准。财务付款前检查收款人和发票主体一致，存在不一致时转人工调查。

## 展示要求

使用泳道区分员工、审批人和财务，显示判断菱形、分支条件与回退箭头。拒绝结束和付款归档是两个不同终点。
