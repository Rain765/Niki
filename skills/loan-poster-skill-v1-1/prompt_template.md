# Prompt Template

Create a premium `[BRAND]` Zambia mobile-loan advertising poster in
`[FORMAT]`.

For Zamloan, use one full-poster prompt that jointly composes
`[BACKGROUND_COLORS]`, `[RIBBON_COLOR]`, one background Z,
`[MODEL_COMBINATION]`, `[HEADLINE_LINE_1] [HEADLINE_LINE_2]`, `[SUBLINE]`, and a
clearly visible smartphone showing `[PHONE_TEXT]`. Keep the Z behind the model,
phone, and copy. Do not apply a Z overlay after generation.

Do not render a standalone brand-name wordmark or logo in the generated image's
top-left corner. For Zamloan, pass the exact attached logo to
`--overlay-logo`; the daemon adds it after generation.
Use the negative prompt in `negative_prompt.md`.
