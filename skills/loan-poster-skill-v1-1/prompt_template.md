# Prompt Template

Create a premium `[BRAND]` Zambia mobile-loan advertising poster in
`[FORMAT]`.

Use `[BACKGROUND_COLORS]`, `[RIBBON_COLOR]`, and one supplied semi-transparent
Z background reference. Set `[HEADLINE_LINE_1]`, `[HEADLINE_LINE_2]`, and
`[SUBLINE]` on the left. Place `[MODEL_COMBINATION]` in
`[SCENE_DESCRIPTION]` on the right, with the main model holding a clearly
visible smartphone showing `[PHONE_TEXT]`.

Do not render a standalone brand-name wordmark or logo in the top-left corner.
Use the negative prompt in `negative_prompt.md`.
